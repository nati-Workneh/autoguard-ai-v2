# Agentic engineering architecture

AutoGuard AI used an AI-assisted, multi-role engineering workflow during development. This is development-time engineering support, not autonomous runtime production agents. The deployed system remains a conventional ML/API/frontend application with human-governed policy decisions.

The workflow provided separated responsibilities, structured handoffs, QA review loops, reproducible correction work and architecture governance. It does not imply that agent use caused any particular predictive metric improvement.
